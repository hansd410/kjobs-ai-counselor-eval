# Interpretation limits

- Results are AI consensus-based assessment. P5 human audit has not been performed.
- Residual F2/F3/F5/F7 judgments are exploratory in this batch. Low prevalence also affects κ for F2/F3. Code-derived components remain distinct.
- GPT rationale is empty in 918/2,250 records (40.8%). All 918 have no GPT residual failure flags. The frozen instruction requests rationale only for failed items. Separate deterministic annotations are not newly generated or recovered original GPT reasoning; original missingness remains. Code F7 occupational-name failures occur in 28 of these records.
- C4 F1 is 47/450 versus C3 36/450. The regex also captures exploratory metaphors; a regex hit is not an independent semantic confirmation of an unfulfilled search promise.
- The optimization budget was exceeded, and candidate selection was manually finalized. C4 exploration rules may learn the evaluation metric. Held-out agreement in direction does not prove absence of metric gaming. Historical preregistration wording should be read with this qualification.
- Subgroup decompositions are post-hoc descriptive analyses. Original row-level bootstrap units and replicate counts are preserved, not silently replaced by persona-cluster resampling.
- Bibliographic DOI/volume checks and independent English translation review remain pending. English files are reference translations, not executable substitutes for Korean probes/regex rules.
- S6 coverage measures mapping, not issue resolution or completeness of secondary-code coverage. Raw feedback is excluded.
- Automatic anonymity scans check known patterns; contextual identity, unknown personal names and permissions still require human review.

- Held-out model metadata differs: the first raw record reports `gemini-3.1-pro`, while the stored summary reports `gemini-3.1-pro-preview`. The release preserves both values and reports this discrepancy; all held-out numerical fields match. It does not infer the actual backend model from an alias.
