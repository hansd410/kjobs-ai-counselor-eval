# Release scope and transformations

This repository was initialized afresh. Internal commits, author metadata, remotes and Git object history were not imported. Its source is an explicit export allowlist.

C3 files use the experiment-start preregistration v1.3 snapshot, confirmed identical to the available research prompt files before export. Source and exported SHA-256 values are recorded in prompts/C3/provenance.json. Replacing identity strings makes public copies byte-different where redactions occur; this is not a change to the internal freeze or an assertion of behavioral equivalence for rerunning models.

All judgments and pairwise records retain their schema, numerical/boolean values, order and join identifiers. Organization and fixture employer names, known study-author/account identifiers, internal paths, project-hosting links, personal contact patterns and email addresses are replaced in public text. Existing reported character counts and scores are retained rather than recalculated from redacted strings. Public-service URLs and cited bibliography author names remain. Raw redaction maps remain private.

Preregistration history and evaluation cards are redacted historical copies, not revised experimental registrations. Internal source tags are cited for provenance but internal Git history is not shipped. No new research hypothesis, score definition or sampling-for-analysis design is introduced. The 300-transcript release sample is a disclosure subset; all statistical estimates still use the full judgment population.

P personas remain test-only. Including them for post-study audit does not authorize training or optimizing on them. Held-out judge records remain a separate sensitivity check, never an ensemble member.

No C4 prompt text, C4 patch hunks, original feedback CSV, full-population transcript file, production engine or API client is included. Numeric derived F1/S6/learning records and short quotations in verdict rationales are explicitly distinguished from raw source data. The named README remains a template until author metadata is confirmed.
